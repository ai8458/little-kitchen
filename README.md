# 热锅搭档 · Little Kitchen

一款原创美术的轻量厨房协作游戏，围绕《Overcooked / 分手厨房》式的取菜、切菜、烹饪、装盘、交餐和洗盘循环制作。使用 Canvas 2D 绘制俯视角厨房，无需安装 npm 依赖，也不使用远程素材。

## 在线游玩

游戏地址：<https://ai8458.github.io/little-kitchen/>。

源码仓库：<https://github.com/ai8458/little-kitchen>。

推荐使用电脑键盘。双人模式为同一台设备上的本地合作。

## 启动

Windows 双击 `启动游戏.cmd`，或在本目录执行 `npm start`。需要 Node.js 18 或更新版本。

浏览器打开 <http://127.0.0.1:4193/>。保留服务进程；关闭服务后游戏不可重新加载。页面使用 ES 模块，请通过 HTTP 服务打开，不要直接双击 HTML。仅监听本机，不涉及联网匹配。

## 操作

| 动作 | 单人 / 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 移动 | WASD | 方向键 |
| 拿取、放下、装盘、交餐 | E | Enter |
| 切菜、洗盘、灭火 | 按住空格 | 按住右 Shift |
| 冲刺 | 左 Shift | / |
| 投掷食材 | Q | 右 Ctrl |
| 切换厨师 | Tab（仅单人） | — |
| 暂停 | Esc | Esc |

单人可以控制两位厨师中的任意一位；另一位保留位置和手中的物品，不会自动行动。双人使用同一键盘，建议支持多键同时按下的键盘。手机提供完整的单人触屏操作。

## 手机游玩

- 开局后进入占满视口的游戏界面，时间、收入、订单、手持物品和操作说明始终可见，不需要上下滚动。
- 竖屏默认放大并跟随当前厨师，常见手机宽度下角色与食材约为初版的 2.6 倍。点顶部「全景」查看整间厨房，再点「跟随」回到放大视角；右下角小地图标示两位厨师的位置。
- 左下摇杆移动，轻推可以慢走、精确靠近工作台。右侧点拿放，长按操作完成切菜、洗盘或灭火。按钮文字会根据当前工作台显示「拿番茄」「盛汤」「交餐」等。
- 支持多指操作；换人、冲刺和投掷都有独立按钮。松手、触控取消、暂停或旋转屏幕后不会残留移动输入。
- 横屏将订单与摇杆放左侧、手持物品与操作按钮放右侧，厨房位于中央。适配手机安全区域和高像素密度屏幕。
- 锅煮好或起火时，即使不在镜头内，也会在画面上方显示提醒。

## 一份沙拉怎么做

1. 走到左侧生菜筐，朝向它按 E 拿生菜。
2. 走到上方切菜板，按 E 放下，再按住空格 2.2 秒，按 E 拿走。
3. 放到空台面。重复操作切好一份番茄，放到另一块空台面。
4. 底部盘架拿一个干净盘子，依次与切好的生菜、番茄交互，完成装盘。
5. 到右侧出餐口按 E。7 秒后脏盘回到底部，拿去水槽清洗；也可以在水槽空手按 E 自动放入回收区的脏盘。

汤需要三份切好的食材入锅：3 番茄、3 洋葱，或 2 洋葱 + 1 番茄。集齐后自动煮 10 秒，拿空盘盛出。煮好后放置 19 秒会起火，用灭火器灭火后，空手取出烧焦食物并丢到垃圾桶。

## 内容和计分

- 三间厨房：阳光小馆、街角食堂、晚高峰。后两间改变中央工作台布局；晚高峰会移动一个切菜板。
- 限时营业和不限时练习。练习不限制订单时间，但汤仍会烧焦。普通关卡分别持续 240、240、210 秒。
- 订单收入 + 最多 30 小费；按从左到右顺序交餐可叠加最多 4 连单，每级额外 +15。超时每单扣 30，分数最低为 0。
- 单人订单等待时间比双人多 30 秒，出单间隔多 8 秒。
- 三星目标与最高分按厨房和单 / 双人模式存储在当前浏览器 localStorage；不存储正在进行的关卡。
- 自动暂停：切换标签、窗口失焦或查看指南时停止游戏计时。
- 音效使用 Web Audio 合成，可以开关。默认关闭。

## 开发与检查

```powershell
npm run check
npm test
npm run build
```

`engine.js` 为独立玩法逻辑，`renderer.js` 绘制厨房与厨师，`app.js` 管理输入、界面与音效。`dist/` 为可以放到静态网站的成品。默认端口 4193，可用 `PORT` 环境变量修改。
